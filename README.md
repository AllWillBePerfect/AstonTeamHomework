# Aston Team Homework

Командный проект на Java, посвящённый реализации алгоритмов сортировки и работе с коллекциями.

## Структура проекта

Проект разделён на три части:

* **`data`** - работа с данными, коллекциями, файлами и их заполнением;
* **`domain`** - основные модели, алгоритмы сортировки, стратегии и бизнес-логика;
* **`ui`** - консольный интерфейс для взаимодействия с пользователем.

## Реализовано

* сортировка объектов пользовательского класса по трём полям;
* несколько алгоритмов сортировки;
* паттерн **Strategy** для выбора алгоритма сортировки;
* паттерн **Builder** для создания объектов;
* заполнение коллекции:

    * случайными данными;
    * вручную;
    * из файла;
* валидация вводимых данных;
* специальная сортировка объектов с учётом чётных и нечётных значений;
* запись результатов в файл;
* использование Stream API;
* многопоточный подсчёт количества вхождений элемента;
* собственная реализация коллекции;
* ручные тесты основных компонентов.

Готовые реализации стандартных алгоритмов сортировки и поиска не используются.

## Технологии

* Java 21
* Gradle

## Запуск

Клонировать репозиторий:

```bash
git clone https://github.com/AllWillBePerfect/AstonTeamHomework.git
cd AstonTeamHomework
```

Запустить проект через Gradle:

```bash
./gradlew run
```

Для Windows:

```bash
gradlew.bat run
```
